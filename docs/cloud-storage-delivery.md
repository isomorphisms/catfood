# Cloud-storage delivery reconciliation

Continues [issue 117](https://github.com/isomorphisms/catfood/issues/117), the
sole successor of the retired cloud-storage branch. `tools.tsv` now admits the
canonical producer and current workbench command registration uses the existing
link/activation mechanism. `commands/cloud-storage.grease` verifies the selected
checkout origin and invokes the declared Grease runtime. It registers the
complete command suite without adding a second checkout/deployment registry.
Host help execution is not authenticated provider or mobile acceptance.

The preserved `google-drive-unzip.ysh` source at
4be1d5a3d603154262f247581dcd76f6a4b317cd has SHA-256
d8f0eee6efbee1125cc227d01448f239c4895a72d254d1a786510aae69a5f97a.
Its Apps Script operation remains independent of ZIP64 selective extraction.
Do not deliver only that old file and claim the current helper-dependent suite.

The existing Android delivery manifest explicitly records missing qualified
helper bundles. An ordinary Grease command is architecture-neutral; socket,
offset/fsync and ZIP helpers have executable ABI identities. The retired
generic ARM Linux upload-helper artifact is not ICK/NDK-qualified Android
delivery. Publish exact stripped Android helper packages, runtime dependencies,
source/package revisions, digests and URLs through `android/packages.tsv` only
after production build/artifact evidence exists. Phone compilation is forbidden.

The C67 facts remain in `android/devices/miro-c67.md`. Current generic delivery
still maps AArch64 to tablet, so C67 must remain blocked until the existing
device/target control-plane work establishes its identity. This change does not
duplicate that broader policy inside the storage producer or mislabel C67 as
tablet. The Java/Play-services IB authorization APK has no native payload and
needs no C67 arm64 port. Its stable private signer/Google registration and
physical authorization remain separate gates.

GitHub Ubuntu, this container, Hetzner, Void, SDF and the physical devices are
separate execution targets. No Void installer or required follower is activated
from an Ubuntu result. Historical jobs ae27f2938d405d382d22363c59dbfa1a8d802772
and db7b39f5ede0… remain unaccepted; issue 117 stays open for package publication,
real host/mobile execution and explicit succession of their obligations.

Kitchen's retained-source fixture task is a disposable host procedure.
Flexible Pipes registers its repeatable execution; AICI validates claim scope.
Private OAuth/session material and corpus bytes never enter their public
receipts. No credential registration or private transfer is enabled here.
